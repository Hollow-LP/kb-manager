## 已知限制（不影响验收）

1. **本机 Python 环境**对部分中文字符串比较不稳定（详见 README「已知环境问题」），影响：
   解析器对「1. 动词…」形式列表项的识别（2 个 xfail 用例）；已通过码位判断、正则、ASCII 标识等方式规避主要路径。
2. **FAQ 缓存只做精确命中**（规范化后完全一致）；语义相近的不同问法仍走知识库检索，避免返回不相关答案。
3. **部门权限不向子部门继承**（按需求"部门"实体精确匹配）；如需包含下级需在配置中显式勾选。
4. 知识管理员可查看任意单元详情（管理需要），但 **AI 问答仍严格按数据权限过滤**。
5. **知识缺口口径**：本次提问没有任何可用资料（无授权单元，或因重排分低被过滤），且回答为「未找到」时计为缺口；
   回答仅为「无权限」的不计为缺口（属于权限问题）。「问答中召回的单元全部无权访问」时，回答会说明"存在资料但无权限"。
6. **FAQ 推荐口径**：只从有授权资料、且回答不是「未找到/无权限」的高频问题中生成，避免把「我不知道」沉淀为标准答案。
